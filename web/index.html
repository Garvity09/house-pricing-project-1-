⚙️ Production MLOps Pipeline Architecture

Decoupled end-to-end Machine Learning pipeline utilizing Object-Oriented Software Design Patterns.

📂
1. Data Ingestion
Factory Pattern

`DataIngestorFactory` instantiates `ZipDataIngestor` or `CSVDataIngestor` based on dataset file extension.

➔
🧹
2. Preprocessing & Split
Strategy Pattern

`DataPreProcessStrategy` cleans columns & computes volume; `DataDivideStrategy` handles train/test splitting.

➔
🧠
3. Model Strategy
Strategy Pattern

Abstract `Model` interface trained with `LightGBM`, `XGBoost`, `RandomForest`, or `LinearRegression`.

➔
📊
4. MLflow Evaluation
Experiment Tracking

Evaluates MSE, RMSE, and $R^2$ Score. Logs parameters, metrics, and model artifacts into MLflow server.

➔
🚀
5. Model Serving
Continuous Deployment

`continuous_deployment_pipeline` validates accuracy threshold and serves active model to Streamlit & Web API.
